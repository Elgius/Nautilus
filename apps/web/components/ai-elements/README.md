AI Elements components adapted from https://github.com/vercel/ai-elements/tree/main/packages/elements/src (Apache-2.0).

Local adapters use the existing Base UI primitives and avoid adding the server AI SDK to the browser. Tool cards intentionally display sanitized status summaries, rather than raw tool parameters or outputs. Inline citation exports cover inline text and links; evidence appears in the Sources disclosure. The Chain of Thought presentation displays observed execution steps only.
